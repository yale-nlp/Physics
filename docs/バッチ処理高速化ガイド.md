# バッチ処理高速化ガイド

## 現在の設定

- **batch_size**: 16
- **リトライ**: max_retries=3, delay=2秒
- **処理時間**: 221問で約40分

## 高速化の方法

### 1. batch_sizeの増加（最も効果的）

**推奨設定**: `batch_size=32` または `batch_size=64`

**効果**: 
- batch_size=16 → 32: 約2倍高速化（理論値）
- batch_size=16 → 64: 約4倍高速化（理論値）

**注意**: OpenAI APIのレート制限に注意が必要です。

### 2. セマフォによる同時リクエスト数制御

レート制限エラーを防ぎつつ、最大限の並列処理を実現します。

### 3. リトライの最適化

- delayを短くする（2秒 → 1秒）
- 指数バックオフを使用

### 4. チェックポイント保存の最適化

- バッチごとではなく、数バッチごとに保存

### 5. 不要な処理の削減

- 進捗表示の最適化
- 不要なログ出力の削減

## 実装例

### 方法1: batch_sizeを増やす（簡単）

```python
# evaluate_mechanics_gpt5_2.py の main関数呼び出し部分を変更
main(llm, base_output_dir, input_jsonl_list, max_lines, batch_size=32)  # 16 → 32
```

### 方法2: セマフォを使用した高度な並列処理

セマフォを使って同時リクエスト数を制御し、レート制限を回避しながら最大限の並列処理を実現します。
