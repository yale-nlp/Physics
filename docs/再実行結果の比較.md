## 論文提出への影響

### 重要な発見

1. **環境依存性の問題**: ANTLR4がインストールされていない環境では、評価結果が大きく異なる
2. **評価方法の一貫性**: SymPyによる数式判定とLLM判定では、判定ロジックが異なる
3. **再現性の確保**: 同じコードでも、環境によって評価結果が変わる可能性がある

### 推奨される対応

1. **完全な再実行**: 全221問をANTLR4インストール済み環境で再実行
2. **環境の明記**: 論文ではPythonバージョン、パッケージバージョンを明記
3. **評価条件の統一**: すべての評価を同じ環境で実行
4. **再現性の確保**: Dockerやconda環境を使用して環境を固定
