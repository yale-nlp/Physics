# 失敗した問題の再実行手順

## 修正内容

`evaluate_mechanics_gpt5_2.py`を修正し、以下の機能を追加しました：

1. **成功した問題のみをスキップ**: `solution≠null`の88問はスキップされます
2. **失敗した問題のみを再実行**: `solution=null`の133問のみを再評価します

## 再実行前の状態

- **総問題数**: 221問
- **成功した問題（スキップ対象）**: 88問
- **失敗した問題（再実行対象）**: 133問

## 実行方法

### 1. 評価スクリプトの実行

```bash
cd /Users/takahashiryoutarou/Desktop/LLM実験/Physics/api_evaluation
python evaluate_mechanics_gpt5_2.py
```

### 2. 実行時の動作

スクリプトは以下のように動作します：

1. **既存結果の読み込み**: `response.jsonl`から成功した問題（`solution≠null`）を読み込みます
2. **スキップ対象の決定**: 成功した88問のIDを`processed_ids`に追加します
3. **新規処理対象の決定**: 失敗した133問のみを処理対象として抽出します
4. **評価の実行**: 失敗した133問のみを再評価します
5. **結果の保存**: 新しい結果を既存の`response.jsonl`に追記します

### 3. 実行中の確認事項

実行中に以下のメッセージが表示されます：

```
既存の結果を検出: 88件の成功済み問題をスキップします（失敗した問題は再実行します）
新規処理対象: 133問
```

### 4. チェックポイント機能

- バッチ処理ごとに中間結果が保存されます
- PCを閉じても、次回実行時に続きから再開できます
- ただし、**成功した問題は再実行されません**（失敗した問題のみ再実行）

## 期待される結果

### 実行後

- **成功した問題**: 88問（既存のまま）
- **再評価された問題**: 133問（新たに評価）
- **合計**: 221問

### 精度の改善

失敗した133問が成功すれば、全体の精度が向上する可能性があります。

## 注意事項

1. **APIコスト**: 133問の再評価にはAPIコストがかかります
2. **実行時間**: 133問の評価には時間がかかります（バッチサイズ24の場合、約6バッチ）
3. **レスポンス構造の問題**: 前回失敗した原因（Responses APIのレスポンス構造の問題）が解決されていない場合、同じエラーが発生する可能性があります

## トラブルシューティング

### すべてのエントリがスキップされる場合

`response.jsonl`が存在しない、または読み込めない可能性があります。確認してください。

### 成功した問題も再実行される場合

`load_processed_ids`関数の`skip_only_successful=True`パラメータが正しく動作しているか確認してください。

### エラーログの確認

実行後、以下のファイルを確認してください：

- `api_evaluation/api_errors.log`: API呼び出しエラー
- `api_evaluation/response_debug.log`: レスポンス構造のデバッグ情報（`content=None`の場合に記録）

## 実行後の統計確認

実行完了後、以下のコマンドで統計を確認できます：

```bash
cd /Users/takahashiryoutarou/Desktop/LLM実験/Physics
python3 -c "
import json
from collections import OrderedDict

entries_by_id = OrderedDict()
with open('outputs/gpt-5.2_mechanics_output/mechanics_dataset/response.jsonl', 'r') as f:
    for line in f:
        if line.strip():
            data = json.loads(line)
            entry_id = data.get('id')
            if entry_id:
                entries_by_id[entry_id] = data

successful = sum(1 for e in entries_by_id.values() if e.get('solution') is not None)
failed = sum(1 for e in entries_by_id.values() if e.get('solution') is None)
accuracies = [e.get('accuracy', 0) for e in entries_by_id.values() if e.get('solution') is not None]

print(f'総問題数: {len(entries_by_id)}')
print(f'成功: {successful}問 ({successful/len(entries_by_id)*100:.1f}%)')
print(f'失敗: {failed}問 ({failed/len(entries_by_id)*100:.1f}%)')
if accuracies:
    print(f'平均精度: {sum(accuracies)/len(accuracies)*100:.2f}%')
"
```
