# 「成功」と「精度」の違い

## 概要

評価結果における「成功」と「精度」は異なる概念です。

## 定義

### 1. **成功（Solutionあり）**

**定義**: API呼び出しが成功し、`\boxed{}`形式の最終回答が抽出できたかどうか

**判定基準**:
- `solution`フィールドが`null`でない
- `final_answers`が空でない（`\boxed{}`形式の回答が抽出できた）

**コード上の判定**:
```python
# 237-245行目: API呼び出し失敗
if answers is None:
    return {
        "solution": None,  # ← 失敗
        "final_answers": [],
        "accuracy": 0,
    }

# 287-295行目: boxed抽出失敗
if not flattened_answers:
    return {
        "solution": answers,  # ← solutionはあるが、final_answersが空
        "final_answers": [],   # ← 抽出失敗
        "accuracy": 0,
    }
```

### 2. **精度（Accuracy）**

**定義**: 成功した問題の中で、正解と一致した割合

**計算式**:
```
精度 = 正解数 / 成功数
```

**コード上の計算**:
```python
# 302-324行目: 正解との比較
for llm_answer in flattened_answers:
    for dataset_answer in dataset_answers:
        equivalency_data = equation_equivilancy.is_equiv(llm_answer, dataset_answer)
        if equivalency_data.get("final_result") is True:
            correct_count += 1
            break

accuracy = correct_count / total_comparisons
```

## 現在の評価結果

### 全体の内訳

```
総問題数: 221問
├─ 成功（solutionあり）: 88問 (39.8%)
│  ├─ 正解（accuracy=1.0）: 55問
│  └─ 不正解（accuracy=0.0）: 33問
└─ 失敗（solutionなし）: 133問 (60.2%)
```

### 精度の計算

```
精度 = 正解数 / 成功数
     = 55 / 88
     = 62.50%
```

**重要**: 精度は「成功した問題のみ」を対象に計算されます。失敗した133問は精度計算に含まれません。

## 具体例

### ✓ 成功かつ正解（accuracy=1.0）

```json
{
  "id": "mechanics/1_9",
  "solution": "完全な回答テキスト...",
  "final_answers": ["\\boxed{正解の式}"],
  "accuracy": 1.0,
  "token_usage": {...}
}
```

- API呼び出し: ✓ 成功
- boxed抽出: ✓ 成功
- 正解判定: ✓ 正解

### ✗ 成功だが不正解（accuracy=0.0）

```json
{
  "id": "mechanics/1_60",
  "solution": "完全な回答テキスト...",
  "final_answers": ["\\boxed{間違った式}"],
  "accuracy": 0.0,
  "token_usage": {...}
}
```

- API呼び出し: ✓ 成功
- boxed抽出: ✓ 成功
- 正解判定: ✗ 不正解

### ✗ 失敗（solutionなし、accuracy=0）

```json
{
  "id": "mechanics/3_4",
  "solution": null,
  "final_answers": [],
  "accuracy": 0,
  "token_usage": null
}
```

- API呼び出し: ✗ 失敗（またはboxed抽出失敗）
- boxed抽出: ✗ 失敗
- 正解判定: 未実施（精度計算に含まれない）

## 失敗の原因

### 1. API呼び出し失敗
- ネットワークエラー
- APIクォータ超過（429エラー）
- タイムアウト

### 2. boxed抽出失敗
- LLMが`\boxed{}`形式で回答しなかった
- 中間ステップで`\boxed{}`を使用した（プロンプト違反）
- 回答が不完全

## まとめ

| 項目 | 定義 | 計算対象 |
|------|------|----------|
| **成功** | API呼び出し成功 + boxed抽出成功 | 全問題（221問） |
| **精度** | 成功した問題の中で正解の割合 | 成功した問題のみ（88問） |

**現在の結果**:
- 成功率: 88/221 = 39.8%
- 精度: 55/88 = 62.50%

成功率が低い理由:
- API呼び出しの失敗が多い（133問）
- reasoningパラメータ使用時の処理時間が長い可能性
- 画像入力によるトークン数の増加
