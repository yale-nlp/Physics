# APIレスポンス問題の修正内容

## 実施した修正

### 1. レスポンス構造の対応強化

**問題**: Responses APIのレスポンス構造が期待と異なる可能性があった

**修正**: 複数のレスポンス形式に対応できるように修正

```python
# 修正前
content = response.output_text if hasattr(response, 'output_text') else None

# 修正後
content = None
if hasattr(response, 'output_text'):
    content = response.output_text
elif hasattr(response, 'output') and response.output:
    # ネストされた構造に対応
    try:
        if isinstance(response.output, list) and len(response.output) > 0:
            output_item = response.output[0]
            if hasattr(output_item, 'content') and output_item.content:
                # ...
    except Exception as e:
        print(f"Warning: Failed to extract content: {e}")
```

### 2. デバッグ出力の追加

レスポンス構造を確認するためのデバッグ出力を追加：

```python
if content is None:
    print(f"Warning: Could not extract content. Response type: {type(response)}")
    print(f"Response attributes: {dir(response)}")
```

### 3. エラーログの記録

エラー情報をファイルに記録する機能を追加：

```python
# エラーログをファイルに記録
error_log_path = os.path.join(os.path.dirname(__file__), "api_errors.log")
with open(error_log_path, "a", encoding="utf-8") as f:
    f.write(f"[{timestamp}] {error_type}: {error_str}\n")
    f.write(f"Traceback:\n{traceback.format_exc()}\n\n")
```

### 4. usage情報の取得方法の改善

usage情報がdict形式の場合にも対応：

```python
# usageが直接dictの場合も対応
elif hasattr(response, 'usage') and isinstance(response.usage, dict):
    usage = {
        "prompt_tokens": response.usage.get('prompt_tokens', 0),
        "completion_tokens": response.usage.get('completion_tokens', 0),
        "total_tokens": response.usage.get('total_tokens', 0),
    }
```
