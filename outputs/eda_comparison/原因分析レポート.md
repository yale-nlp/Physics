# 精度差の原因分析レポート

## 実行サマリー

**gpt-4o_mechanics_output**の精度が**gpt-4o_output**より**20.36%低い**原因を特定しました。

## 主な原因

### 1. **Sympyエラー（LaTeXパースエラー）**

#### 問題の詳細
- **gpt-4o_mechanics_output**: 1032個のSympyエラーが発生（エラー率98.88%）
- **gpt-4o_output**: Sympyエラー0個（エラー率0%）

#### エラーメッセージ
```
LaTeX parsing requires the antlr4 Python package, provided by pip (antlr4-python3-runtime) or conda (antlr-python-runtime), version 4.11
```

#### 影響
1. **LaTeXパースができない**: `parse_latex`関数が`antlr4-python3-runtime`パッケージを必要とするが、インストールされていない
2. **Sympy評価ができない**: LaTeXパースが失敗すると、Sympyによる数式の等価性評価ができない
3. **LLM評価への依存**: Sympy評価ができない場合、LLMによる比較にフォールバックするが、精度が低下

### 2. **Sympy Error Correct Ratioの違い**

- **gpt-4o_mechanics_output**: 0.0000（Sympyエラーが発生した場合、LLMによる補正が機能していない）
- **gpt-4o_output**: 0.0635（Sympyエラーが発生した場合でも、LLMによる補正が機能している）

### 3. **評価プロセスの違い**

#### 正常な評価フロー（gpt-4o_output）
1. LaTeX式をパース → Sympyで評価
2. SympyでFalseの場合 → LLMで再評価
3. 最終結果を決定

#### 異常な評価フロー（gpt-4o_mechanics_output）
1. LaTeX式をパース → **エラー（antlr4未インストール）**
2. Sympy評価スキップ → LLM評価に直接フォールバック
3. **LLM評価も正しく機能していない可能性**

## 根本原因

### 技術的な原因
1. **依存パッケージの不足**: `antlr4-python3-runtime`パッケージがインストールされていない
2. **評価環境の違い**: gpt-4o_mechanics_outputの評価時に、必要なパッケージがインストールされていない環境で実行された可能性

### 評価ロジックへの影響
```python
# equation_equivilancy.pyの評価フロー
if "\\text" in expr1 or "\\text" in expr2:
    # LLM評価のみ
else:
    try:
        sympy_expr1 = parse_latex(expr1_core)  # ← ここでエラー
        sympy_expr2 = parse_latex(expr2_core)  # ← ここでエラー
        # Sympy評価
    except Exception as e:
        # LLM評価にフォールバック
```

gpt-4o_mechanics_outputでは、`parse_latex`が常にエラーを発生させ、Sympy評価がスキップされ、LLM評価のみに依存している状態です。

## 推奨される対策

### 1. **即座の対策**
- `antlr4-python3-runtime`パッケージをインストール
- 評価環境を統一し、必要な依存パッケージがすべてインストールされていることを確認

### 2. **長期的な対策**
- 評価環境の依存関係を明確に文書化
- CI/CDパイプラインで依存パッケージのチェックを追加
- エラーハンドリングの改善（Sympyエラー時のLLM評価の精度向上）

### 3. **再評価の推奨**
- 依存パッケージをインストールした環境で、gpt-4o_mechanics_outputを再評価することを推奨
- 再評価により、精度が向上する可能性が高い

## 結論

**gpt-4o_mechanics_outputの精度が低い主な原因は、`antlr4-python3-runtime`パッケージがインストールされていないことによるLaTeXパースエラーです。**

このエラーにより：
1. Sympyによる数式評価ができない
2. LLM評価のみに依存するが、その精度も低い
3. 結果として、全体の精度が20.36%低下

**対策**: 依存パッケージをインストールして再評価することで、精度の向上が期待できます。
